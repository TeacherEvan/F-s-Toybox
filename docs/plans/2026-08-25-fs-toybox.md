# F's-Toybox — Implementation Plan

> **For Claude/Hermes:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build `F's-Toybox`, a WebGL2 browser-rendered animated Linux desktop wallpaper with a master God Panel that controls per-element motion, save/load to `scene.json`, and eight entity kinds (galaxy, planet, moon, shooting star, black hole, ring, nebula, comet) — all on a per-element scene graph. Replaces the "Cosmic Penguin" concept with the same render pipeline minus the bird.

**Architecture:** Single `index.html` (no build step) carrying forward the proven WebGL2 fragment-shader pipeline from `docs/concept/index.html`. JS owns the scene graph (entities with `motion` + `render` properties); entities are uploaded each frame as a **64×4 `RGBA32F` data texture** (one row per entity, four `vec4` slots), and the fragment shader walks a fixed-size loop over up to 64 rows. Per-entity code is inlined into one GLSL function; no per-kind shader programs. Penguin SDF, eye quasar, and the eight global slider uniforms are deleted; `evaluateQuasar`'s body is reused for the Black Hole kind with the three slider uniforms (`uSpikes`, `uJet`, `uIntensity`) replaced by per-entity values read from the data texture. Determinism: the URL params `?seed=42&t=0` freeze the engine clock and seed any random number generation, enabling reproducible visual diff golden images.

**Tech Stack:** Vanilla JS, WebGL2 (raw, no library), HTML/CSS for the God Panel. Tests: **Vitest** (unit) + **Playwright** with Chromium (E2E + visual diff). Node 22.x (matches `engines` if added). No bundler, no `package.json` for the app itself — but a `package.json` for the test harness (Vitest + Playwright devDeps only).

**Effort:** ~1 week | **Surfaces touched:** 4 files (`index.html`, `scene.json`, `README.md`, `tests/`) | **New entities:** 8 (in JSON, not DB) | **Feature flag:** none — single user, no ramp needed.

## Data Flow

### 4.1 Per-frame render loop (solid path)

```
[Browser raf]
     │
     ▼
JS scene state (in-memory, plain objects)
     │
     ├── packEntitiesToDataTexture() ──┐
     │                                  │
     ▼                                  ▼
gl.texImage2D(MAX_ENTITIES rows, 1 col, RGBA32F)   gl.uniform1i(uEntityTex, 0)
     │                                  │
     └──────────────┬───────────────────┘
                    ▼
fragment shader main() {
  vec3 col = renderBackground(uv, time);
  for (int i = 0; i < MAX_ENTITIES; i++) {
    Entity e = readEntity(i);
    if (!e.visible) continue;
    col = renderEntity(e, uv, time, col);
  }
  fragColor = vec4(grade(aces(col)), 1.0);
}
                    │
                    ▼
              gl.drawArrays()
                    │
                    ▼
               [display]
```

```
User clicks [Save]
     │
     ▼

     │                                                   │
     │                                                   ▼
     │                                          [file saved to ~/Downloads]
     │
     └── JSON.stringify(scene) ── localStorage.setItem('mad.scene', ...)
                                       │
                                       ▼
                                 [autosave on every edit too]


User clicks [Load] (or drops scene.json on canvas)
     │
     ▼
FileReader.readAsText() ── JSON.parse() ── validateScene() ── applyScene()
                                                       │
                                              (invalid) │
                                                       ▼
                                                  red toast, scene unchanged
```

### 4.3 Edit propagation (solid = synchronous)

```
[User drags X slider on right panel]
     │
     ▼
input event ── scene.updateEntity(id, {position: {x: newX}})
     │
     ├── localStorage.setItem('mad.scene', ...)         (autosave, debounced 200ms)
     │
     ├── entityListEl.update()                          (left column re-renders)
     │

```

## Risk Table

| # | Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|---|
| 1 | WebGL2 uniform cap exceeded: `MAX_ENTITIES = 64` × 16 vec4s/entity = 256 vec4s — over the WebGL2 minimum `GL_MAX_FRAGMENT_UNIFORM_COMPONENTS` of **896** (NOT 1024 — the 1024 figure is the WebGL 1.0 / GLSL ES 1.00 number; ES 3.0 minimum is 896, verified against Khronos `glGet` reference) | Medium | High | **Data texture**, not uniforms. Entities live in a 64×4 `RGBA32F` texture (no uniform count used). If the engine reports `MAX_FRAGMENT_UNIFORM_COMPONENTS < 896` at boot, it aborts with a spec-violation error. |
| 2 | Shader compile time grows with kind count | Medium | Low | One shader, fixed `MAX_ENTITIES = 64`, all 8 kinds' `render<K>()` functions always compiled. Branch on `entity.kind` inside the loop. Measure: `gl.getShaderInfoLog` post-compile should be empty. |
| 3 | Save/Load JSON desync | Low | Medium | `schemaVersion: 1` field. `validateScene()` rejects on mismatch; UI shows red toast. Round-trip test in M10. |
| 4 | Orbit cycle (A → B → A) or depth > 8 | Low | High | DFS at save + edit time; reject with C-style toast (mockup C). Tested in M2. |
| 5 | `localStorage` blocked in kiosk wallpaper engine | Medium | Low | Save-to-download is canonical. localStorage is convenience only; if `setItem` throws, swallow and log a warning — app still works. |
| 6 | WebGL2 unavailable (older / headless GPU) | Low | High | Keep `paint2DFallback` from reference (lines 473-493). Test in M11 by running Chromium with `--disable-webgl`. |
| 7 | Pointer-event collision: plain drag (camera) vs. shift-drag (selection) | Medium | Medium | Explicit modifier key. Documented in README. Shift+drag in Playwright uses `page.keyboard.down('Shift')` between `mouse.down()` and `mouse.move()`. |

```js
// JS-side string kinds. GLSL-side KIND_GPU enum (in src/pack.js) maps these
// to integer slot codes; the packer handles the translation on every upload.
export const ENTITY_KINDS = ['galaxy','planet','moon','ring','shootingStar','blackHole','nebula','comet'];

// The order in the array is significant: it's the order in which
// +Add buttons appear in the God Panel toolbar (M3.1). Keep stable.

const DEFAULTS = {
  galaxy:        { motion: { spin: 0.4, pulse: 0.2, wobble: 0.0 },
                   render: { armCount: 2, armSharp: 0.7, coreSize: 0.5,
                             coreBright: 1.5, dust: 0.6 } },
  planet:        { motion: { spin: 0.5, wobble: 0.0, tilt: 0.0, bandingSpeed: 0.3 },
                   render: { radius: 0.08, banding: 0.4, atmosphere: 0.0 } },
  moon:          { motion: { spin: 0.3, wobble: 0.0, libration: 0.0 },
                   render: { radius: 0.04, craterDensity: 0.5, albedo: 0.7 } },
  shootingStar:  { motion: { vx: 0.4, vy: 0.2, lifetime: 3.0 },
                   render: { length: 0.3, thickness: 0.005, brightness: 1.5, trailFade: 0.8 } },
  blackHole:     { motion: { spin: 0.3, accretionSpeed: 0.6, lensingPulse: 0.0 },
                   render: { schwarzschildRadius: 0.05, accretionRadius: 0.12,
                             jetReach: 0.32, spikeSharpness: 280 } },
  ring:          { motion: {}, // inherits parent
                   render: { innerRadius: 0.12, outerRadius: 0.18, tilt: 0.3,
                             opacity: 0.6, banding: 0.4 } },
  nebula:        { motion: { drift: 0.02, turbulence: 0.4 },
                   render: { radius: 0.25, density: 0.6, softness: 0.7 } },
  comet:         { motion: { orbitRadius: 0.4, orbitSpeed: 0.3, orbitPhase: 0, tailWobble: 0.05 },
                   render: { nucleusRadius: 0.02, tailLength: 0.15, tailWidth: 0.02, tailFade: 0.7 } },
};

let _idCounter = 0;
function uuid() {
  _idCounter++;
  return `ent-${Date.now().toString(36)}-${_idCounter.toString(36)}`;
}

export function createEntity(kind) {
  if (!ENTITY_KINDS.includes(kind)) throw new Error(`Unknown kind: ${kind}`);
  return {
    id: uuid(),
    kind,
    name: defaultName(kind),
    visible: true,
    position: { x: 0, y: 0 },
    orbit: { enabled: false, parentId: null, radius: 0.2, speed: 0.4, phase: 0 },
    scale: 1,
    rotation: 0,
    color: { h: 200, s: 0.6, b: 0.85 },
    motion: { ...DEFAULTS[kind].motion },
    render: { ...DEFAULTS[kind].render },
  };
}

function defaultName(kind) {
  const names = { galaxy: 'Galaxy', planet: 'Planet', moon: 'Moon',
                  shootingStar: 'Shooting Star', blackHole: 'Black Hole',
                  ring: 'Ring', nebula: 'Nebula', comet: 'Comet' };
  return names[kind];
}

export class Scene {
  constructor() { this.entities = []; this.camera = { x:0, y:0, zoom:1 };
                  this.globalMotion = { paused:false, timeScale:1 };
                  this.background = { enabled:true, spiralSpeed:0.8, starDensity:1 };
                  this.schemaVersion = 1; }
  addEntity(e) { this.entities.push(e); return e; }
  removeEntity(id) { this.entities = this.entities.filter(e => e.id !== id); }
  updateEntity(id, patch) {
    const e = this.entities.find(e => e.id === id);
    if (!e) return false;
    Object.assign(e, patch);
    return true;
  }
}
```

#### Task 4.3 — Data texture for entities (64×4 layout, parent-slot encoding)

**Files:** Modify `index.html`, Create `src/pack.js`.

**Pre-flight (the broken thing this fixes):** the earlier draft of this plan used a 64×1 `RGBA32F` texture and tried to sample rows 2/3/4 with `vec2(0, 1/4)` Y-offsets. That returns the **border color** on a 1-tall texture, so every entity's last three vec4s would read as zeros. This task uses 64×4 instead. **Do NOT change the texture dimensions back to 64×1** — the golden-image tests in M5+ are pinned to the 64×4 layout.

**Step 1:** Add `src/pack.js` (importable from `index.html` as a module, OR inlined as a string in the `<script type="module">` block — pick what the M1 stub already established):

```js
import { KIND_GPU } from './scene.js';

const MAX_ENTITIES = 64;
const SLOTS_PER_ENTITY = 4; // 4 vec4s per row

export function packEntitiesToDataTexture(scene, time) {
  // 64 columns × 4 rows × 4 floats = 1024 floats
  // (one column = one entity; one row = one vec4 slot of that entity)
  const data = new Float32Array(MAX_ENTITIES * SLOTS_PER_ENTITY * 4);

  // First pass: build slotIndex lookup (entity.id → row index)
  const slotOf = new Map();
  scene.entities.forEach((e, i) => { if (i < MAX_ENTITIES) slotOf.set(e.id, i); });

  // Second pass: resolve world positions and write rows
  for (let i = 0; i < scene.entities.length && i < MAX_ENTITIES; i++) {
    const e = scene.entities[i];
    const world = resolveWorldPosition(e, scene, slotOf, time);
    const isChainRoot = !e.orbit.enabled || e.orbit.parentId == null;
    const parentSlot = (!isChainRoot && slotOf.has(e.orbit.parentId))
                       ? slotOf.get(e.orbit.parentId) : 255;
    const base = i * SLOTS_PER_ENTITY * 4;

    // vec4[0]: (kind, pos.x, pos.y, parentSlot OR base.rotation)
    data[base + 0] = KIND_GPU[e.kind.toUpperCase()] ?? 0;
    data[base + 1] = world.x;
    data[base + 2] = world.y;
    data[base + 3] = isChainRoot ? e.rotation : parentSlot;

    // vec4[1]: (h/360, s, b, scale)
    data[base + 4] = e.color.h / 360;
    data[base + 5] = e.color.s;
    data[base + 6] = e.color.b;
    data[base + 7] = e.scale;

    // vec4[2]: (motion.p0..p3) — per-kind, see §6 of design
    const m = e.motion;
    data[base + 8]  = m.p0 ?? 0;
    data[base + 9]  = m.p1 ?? 0;
    data[base + 10] = m.p2 ?? 0;
    data[base + 11] = m.p3 ?? 0;

    // vec4[3]: (render.r0..r2, base.rotation) — last slot stores base.rotation
    // when this entity is a chain root and rotation lives in vec4[0].w.
    const r = e.render;
    data[base + 12] = r.r0 ?? 0;
    data[base + 13] = r.r1 ?? 0;
    data[base + 14] = r.r2 ?? 0;
    data[base + 15] = isChainRoot ? 0 : e.rotation; // only used when not chain root
  }
  return data;
}

function resolveWorldPosition(entity, scene, slotOf, time) {
  if (!entity.orbit.enabled || !entity.orbit.parentId) return entity.position;
  const parent = scene.entities.find(e => e.id === entity.orbit.parentId);
  if (!parent) return entity.position; // parent deleted mid-frame: safe fallback
  const parentWorld = resolveWorldPosition(parent, scene, slotOf, time);
  const theta = entity.orbit.phase + time * entity.orbit.speed;
  // Y-up convention: positive speed = counter-clockwise on screen.
  return {
    x: parentWorld.x + Math.cos(theta) * entity.orbit.radius,
    y: parentWorld.y + Math.sin(theta) * entity.orbit.radius,
  };
}

export function uploadEntityTexture(gl, data) {
  // 64 wide × 4 tall, RGBA32F
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA32F, 64, 4, 0, gl.RGBA, gl.FLOAT, data);
}
```

**Step 2:** Add `readEntity(int i)` GLSL helper in the fragment shader. **Crucial:** the texture is 64 wide × 4 tall. We sample the four vec4s along Y at fixed U for the row:

```glsl
#define MAX_ENTITIES 64
uniform sampler2D uEntityTex;

struct Entity {
  int kind;
  vec2 pos;
  float parentSlot;   // 0..63 or 255
  vec3 color;
  float scale;
  vec4 motion;        // p0..p3
  vec4 render;        // r0..r3
  float baseRotation; // read from vec4[0].w for chain roots, vec4[3].w otherwise
};

Entity readEntity(int i) {
  float u = (float(i) + 0.5) / float(MAX_ENTITIES);
  vec4 v0 = texture(uEntityTex, vec2(u, 0.5 / 4.0));
  vec4 v1 = texture(uEntityTex, vec2(u, 1.5 / 4.0));
  vec4 v2 = texture(uEntityTex, vec2(u, 2.5 / 4.0));
  vec4 v3 = texture(uEntityTex, vec2(u, 3.5 / 4.0));
  Entity e;
  e.kind        = int(v0.x);
  e.pos         = v0.yz;
  e.baseRotation = v0.w;
  e.color       = v1.xyz;
  e.scale       = v1.w;
  e.motion      = v2;
  e.render      = vec4(v3.xyz, 0.0);
  // parentSlot: if v0.w > 63.5 (i.e. is the rotation, not a slot index), then
  // look up parent from vec4[3].w. Else v0.w IS the parent slot.
  // The packer convention: chain root has v0.w = rotation (any float, but
  // always < 2π), child has v0.w = parent slot (integer 0..63).
  // Heuristic: v0.w is a slot iff v0.w is a non-negative integer ≤ 63.
  // Implement as: e.parentSlot = (v0.w <= 63.5 && fract(v0.w) < 0.01) ? v0.w : -1.0;
  // For the empty-loop smoke below, we don't need this yet.
  e.parentSlot  = -1.0;
  return e;
}
```

```js
const MAX_PARTICLES = 256;

export function packParticleDataTexture(scene) {
  const data = new Float32Array(MAX_PARTICLES * 2 * 4);  // 2 vec4s per particle
  let row = 0;
  for (const e of scene.entities) {
    if (e.kind !== 'field') continue;
    const target = Math.min(e.field.particleCount, MAX_PARTICLES - row);
    for (let i = 0; i < target; i++) {
      const p = e.particles[i] ?? defaultParticle(e.field, i);
      const base = row * 2 * 4;
      // vec4[0] = (age, phase, radius, speedJitter)
      data[base + 0] = p.age;
      data[base + 1] = p.phase;
      data[base + 2] = p.radius;
      data[base + 3] = p.speedJitter;
      // vec4[1] = (brightness, 0, 0, 0)
      data[base + 4] = p.brightness;
      data[base + 5] = 0;
      data[base + 6] = 0;
      data[base + 7] = 0;
      row++;
    }
  }
  return data;
}

function defaultParticle(field, i) {
  return {
    age: 0,
    phase: (i / Math.max(1, field.particleCount)) * Math.PI * 2,
    radius: 0.05 + (i / field.particleCount) * 0.3,
    speedJitter: 0.8 + 0.4 * Math.sin(i * 1.7),
    brightness: 1.0
  };
}

export function uploadParticleTexture(gl, data) {
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA32F, 256, 1, 0, gl.RGBA, gl.FLOAT, data);
}
```

```js
        const dt = now - last;
        last = now;
        if (count > 0) samples.push(1000 / dt);
        count++;
        if (count < 300) requestAnimationFrame(tick);
        else {
          samples.sort((a, b) => a - b);
          const trim = Math.floor(samples.length * 0.1);
          const mid = samples.slice(trim, samples.length - trim);
          resolve(mid.reduce((s, v) => s + v, 0) / mid.length);
        }
      };
      requestAnimationFrame(tick);
    });
  });
  // 2 fps headroom for jitter / CI variance.
  expect(fps).toBeGreaterThanOrEqual(58);
});
```

## Open decisions (resolved during the second-pass review)

1. **Data texture slot assignment:** every frame the packer walks `scene.entities` in array order; deleted entities shift the rest down. Slot index = array index. (Design §5.1.)
2. **GLSL source location:** one inlined `FRAG` template literal in `index.html`. (Design §5.)
3. **Test harness for shader:** Vitest for JS units, Playwright visual diff for the shader. Determinism via `?seed=42&t=0` URL params (Task 4.3 Step 5).
4. **`evaluateQuasar` recycling:** body ported, three global uniforms replaced with per-entity values from the data texture. (Risk #10.)
5. **Data texture shape:** 64×4 (NOT 64×1). The 1-tall shape would return border color for vec4s 2/3/4. (Risk #13.)
6. **`KIND_GPU` enum:** pinned in design §3.1. `0=UNUSED, 1=GALAXY, 2=PLANET, 3=MOON, 4=RING, 5=SHOOTING_STAR, 6=BLACK_HOLE, 7=NEBULA, 8=COMET`. The packer translates; the shader branches on int.
7. **HSV units:** stored in JSON as degrees (0..360) for h, 0..1 for s/b; converted to 0..1 by the packer. (Design §3.1, Risk-table item 15.)
8. **Y-axis sign convention:** UV-space +y = screen +y (UP). Positive `speed` = counter-clockwise on screen. (Design §3.3.)
9. **Scale × render.radius math:** effective size = `render.radius * scale`. Rings ignore `scale` (parent provides world scale). (Design §3.4.)
10. **Rotation math:** effective intrinsic angle = `base.rotation + t * motion.spin`. (Design §3.4.)
11. **Linux wallpaper engines:** `plasma6-wallpapers-webengine` (KDE 6), Chromium `--window-type=desktop` (Hyprland/Sway), xwinwrap (X11 only). Drop KDE tech preview + Variety. (Design §12, Risk #14, M11.1.)
